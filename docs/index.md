# Agentic Chaos

How does the application behave when a dependency fails?

## What it does

Fault events, experiment reports, and resilience evidence.

## What you need

A wrapped callable or experiment target plus fault configuration.

## Start here

Inject a timeout into a local dummy search call.

[Follow the quickstart](developer-guide.md#quickstart).

## Scope

A fault being injected does not prove successful recovery. Inspect application behavior and define recovery assertions.

[Read the detailed developer guide](developer-guide.md).
